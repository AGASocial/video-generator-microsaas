     * - Signature encoding: hex (check KLING-API-NOTES.md Q2)

    function verifyKlingWebhookSignature(
      payload: string,
      signature: string,
      timestamp: string,
      secret: string
    ): boolean {
      try {
        if (!timestamp) {
          console.error("[KlingWebhook] Missing timestamp for signature verification");
          return false;
        }

        // STAT-05: Replay attack prevention — reject events older than 5 minutes
        const timestampNum = parseInt(timestamp, 10);
        const currentTime = Math.floor(Date.now() / 1000);
        const timeDifference = Math.abs(currentTime - timestampNum);
        const fiveMinutes = 5 * 60;

        if (timeDifference > fiveMinutes) {
          console.error(
            `[KlingWebhook] Timestamp too old. Difference: ${timeDifference}s (max: ${fiveMinutes}s)`
          );
          return false;
        }

        // [EXECUTOR: Use signing payload format from KLING-API-NOTES.md Q2]
        // Assumed format: timestamp.rawBody (same as OpenAI)
        const signedPayload = `${timestamp}.${payload}`;

        // [EXECUTOR: Use encoding from KLING-API-NOTES.md Q2]
        // Assumed: hex (same as OpenAI)
        const expectedSignature = crypto
          .createHmac("sha256", secret)
          .update(signedPayload)
          .digest("hex");

        // STAT-03: Timing-safe comparison (prevents timing attacks)
        const signatureBuffer = Buffer.from(signature, "hex");
        const expectedBuffer = Buffer.from(expectedSignature, "hex");

        if (signatureBuffer.length !== expectedBuffer.length) {
          console.error("[KlingWebhook] Signature length mismatch");
          return false;
        }

        const isValid = crypto.timingSafeEqual(signatureBuffer, expectedBuffer);
        if (!isValid) {
          console.error("[KlingWebhook] Signature verification failed");
        }
        return isValid;
      } catch (error) {
        console.error("[KlingWebhook] Signature verification error:", error);
        return false;
      }
    }

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kling servers → POST /api/webhook/video-complete | Untrusted: any caller can POST to this endpoint; signature verification is the only gate |
| Webhook handler → video_history (Supabase) | Service-side write; no user session involved |
| Webhook handler → Kling CDN (download) | Outbound fetch to cdn.klingai.com; URL comes from Kling's own webhook payload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | POST /api/webhook/video-complete | mitigate | HMAC-SHA256 signature verification with KLING_WEBHOOK_SECRET; timing-safe comparison via crypto.timingSafeEqual (STAT-03) |
| T-04-02 | Tampering | Webhook replay attack | mitigate | Timestamp check: reject events with abs(now - timestamp) > 5 minutes (STAT-05); idempotency check: skip if video status already terminal (STAT-04) |
| T-04-03 | Repudiation | Insufficient log context | mitigate | Every error path logs [KlingWebhook] + videoId + taskId + error message (ERR-03); sufficient context to reconstruct event in production |
| T-04-04 | Information Disclosure | KLING_WEBHOOK_SECRET in logs | mitigate | Secret is never logged; only its presence/absence is logged ("KLING_WEBHOOK_SECRET not configured"); error messages do not include the secret value |
| T-04-05 | Elevation of Privilege | KLING_WEBHOOK_SKIP_VERIFICATION=true in production | mitigate | This env var defaults to true in .env.dev only; KLING_WEBHOOK_SECRET must be set in .env.prod; plan 01 acceptance criteria verified the dev setting; Phase 3 (INFRA-01) verifies production env vars |
| T-04-06 | Tampering | Kling CDN URL substitution | accept | The klingVideoUrl comes from Kling's own authenticated webhook payload (already signature-verified); a forged URL would require breaking the HMAC; risk is low given the signature gate |
| T-04-07 | Denial of Service | Repeated replay of same event | mitigate | Idempotency check returns 200 immediately without processing; DB read is O(1) indexed on job_id; no amplification risk |
</threat_model>
